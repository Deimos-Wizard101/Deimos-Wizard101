# Early Myth questing profile for before Humongofrog and Orthrus.
# Keep the in-game deck small: Mythblade, Myth Trap, Myth Prism, Golem Minion,
# Troll, Cyclops, Blood Bat, and a wand hit.
# Sun damage enchants are optional; this profile does not require treasure cards, pets,
# gear cards, off-school spells, or minion-heavy automation.
# The optional questing settings above are scoped to this profile when it is loaded.
# Deimos adds profile-specific combat logic for this profile only:
# - Myth Prism is only used against Myth enemies, and discarded against non-Myth enemies.
# - Mythblade and Myth Trap are not recast when matching effects are already detected.
# - Blood Bat is only used as a finisher when the selected enemy is at or below 150 HP.
# - High-health enemies use Mythblade, Myth Trap, optional Golem Minion, Troll, Cyclops, then pass.
# The line below is a conservative fallback for the normal playstyle parser.

?(enemy.health > 150) "Mythblade" @ self | ?(enemy.health > 150) "Myth Trap" @ enemy | ?(enemy.health > 150) "Golem Minion" @ self | ?(enemy.health > 150) "Troll" [any<mod_damage>] @ enemy | ?(enemy.health > 150) "Cyclops" [any<mod_damage>] @ enemy | ?(enemy.health <= 150) "Blood Bat" [any<mod_damage>] @ enemy | ?(enemy.health <= 150) "Troll" [any<mod_damage>] @ enemy | ?(enemy.health <= 150) "Cyclops" [any<mod_damage>] @ enemy | ?(enemy.health <= 150) any<damage> @ enemy | pass
