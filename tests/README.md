Run `uv run --group dev python -m unittest discover -s tests -v` from the repository root. The tests use the vendored grammar and transformer, the actual backend and GUI dispatch branches, and native Qt widgets. They do not attach a Wizard101 client. On Linux they stub the Windows memory base classes required to import parser definitions; the grammar, enums and transformer come from this checkout. Live memory reads and combat behavior still need a Windows client check.
